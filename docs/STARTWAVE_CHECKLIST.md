# StartWave Checklist

## Назначение

Документ содержит единый чек-лист проверки страниц StartWave перед публикацией.

Документ будет постепенно заполняться и уточняться по мере роста проекта.

## Основные разделы

### Контент

- Тема раскрыта простым языком.
- Нет лишнего текста.
- Ответ можно найти быстро.
- Статья помогает решить задачу игрока.

### Источники

- Проверен официальный сайт Black Desert Online.
- Проверены официальные патчноуты.
- Проверен BDO Codex.
- По возможности выполнена проверка в игре.

### Структура

- Есть понятные заголовки.
- Есть короткие блоки.
- Есть связанные материалы.
- Есть следующий шаг обучения.

### Техническая проверка

- HTML проверен.
- CSS проверен.
- JavaScript проверен.
- Нет битых ссылок.
- Нет отсутствующих изображений.
- Выполнен `git diff --check`.

## Статус

Каркас создан. Чек-лист будет расширяться после проверки первых крупных страниц.
