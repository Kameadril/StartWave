# StartWave Release

## Назначение

Документ описывает порядок подготовки релизов StartWave: что нужно проверить перед публикацией изменений и как фиксировать состояние проекта.

Документ будет постепенно заполняться по мере появления стабильного релизного процесса.

## Основные разделы

### Подготовка релиза

- Проверить список изменённых файлов.
- Проверить новые страницы.
- Проверить документацию.
- Проверить навигацию и связанные материалы.

### Технические проверки

- Проверить HTML.
- Проверить CSS.
- Проверить JavaScript.
- Проверить ссылки.
- Проверить изображения.
- Проверить адаптивность.

### Документация релиза

- Обновить changelog.
- Проверить версию проекта.
- Зафиксировать важные изменения.
- Описать известные ограничения.

### Публикация

- Выполняется только после подтверждения пользователя.
- Commit и push не выполняются автоматически.

## Статус

Каркас создан. Регламент будет уточняться после следующих релизов StartWave.
