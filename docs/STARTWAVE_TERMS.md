# StartWave Terms

## Назначение

Документ хранит единый словарь терминов StartWave и Black Desert Online, чтобы все страницы использовали одинаковые названия механик, разделов и игровых понятий.

Документ будет постепенно заполняться по мере развития базы знаний.

## Основные разделы

### Термины StartWave

- Маршрут обучения.
- Граф знаний.
- Следующий шаг.
- Финальный блок.

### Термины Black Desert Online

- Рабочие.
- Узлы.
- Очки влияния.
- Выносливость.
- Производство.

### Правила написания

- Единые русские названия.
- Оригинальные английские названия при необходимости.
- Пометки для спорных или требующих проверки терминов.

### Проверка терминов

- Официальный сайт.
- Официальные патчноуты.
- BDO Codex.
- Проверка в игре.

## Статус

Каркас создан. Термины будут добавляться постепенно при подготовке новых статей.
