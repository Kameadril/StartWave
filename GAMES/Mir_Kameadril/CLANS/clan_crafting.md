# Клановый крафт

Клан может назначать специализированных мастеров. Кузнец с профессией бронника создаёт броню уровня 40+ по специальным рецептам.

## Заданные бонусы

- Для участников своего клана: стоимость изготовления ниже на 5% ресурсов.
- Для кузнеца: возврат 1% материалов.

Следует определить источник рецептов, учёт принадлежности к клану и защиту от злоупотреблений.
