# Мир Камеадрил

Документационный каркас MMORPG-концепции о живом мире, историю которого создают игроки через добычу, ремесло, торговлю, территориальные войны, кланы и королевства.

## Главный принцип

**Каждый игрок важен.** Добытчики создают сырьё, ремесленники — снаряжение, торговцы связывают регионы, воины защищают территории, кланы строят государства, а короли отвечают за ход истории.

## Статус

Версия 0.1 — базовая структура GDD. Документы фиксируют только исходные правила концепции; числовой баланс, контент и техническая реализация будут уточняться позже.

## Правило развития документации

Каждое новое решение должно указывать цель, влияние на игроков, связь с другими системами, необходимые данные и открытые вопросы. Новые системы не добавляются без игровой необходимости.
