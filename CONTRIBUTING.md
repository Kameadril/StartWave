# Правила разработки StartWave

## Основные принципы

- Не нарушать существующий стиль.
- Новые страницы сначала создаются как Version 1.0 — контент.
- После утверждения дизайна переводятся в Version 2.0.
- Затем получают интерактив Version 3.0.
- AI добавляется последним.

Перед каждым большим изменением необходимо проверить, не существует ли уже похожее решение.

Главная цель — единая архитектура проекта.

## Подход к изменениям

- Сначала анализировать текущую структуру.
- Не переписывать рабочие решения без причины.
- Делать небольшие аккуратные изменения.
- Не смешивать разные задачи в одном изменении.
- Не добавлять временные решения, если можно сразу заложить расширяемую основу.

## Версии страниц

### Version 1.0 — контент

Страница отвечает на вопрос пользователя и содержит базовую структуру.

### Version 2.0 — дизайн

Страница получает утверждённый визуальный стиль раздела.

### Version 3.0 — интерактив

Страница получает интерактивные элементы, если они реально помогают пользователю.

### AI

AI добавляется только после того, как структура, данные и пользовательский сценарий уже понятны.
