# Design System StartWave

## Назначение

Этот документ фиксирует основные элементы интерфейса StartWave, чтобы новые страницы сохраняли единый стиль.

## Проверяемые элементы

- Карточки
- Высота
- Отступы
- Скругления
- Тени
- Hover
- Hero
- Заголовки
- Кнопки
- Цвета
- Иконки
- Размеры
- Анимации
- Grid
- Контейнер
- Максимальная ширина

## Общий принцип

Новый интерфейс должен выглядеть как часть StartWave, а не как отдельный эксперимент.

Если для нового блока нужен новый визуальный паттерн, сначала нужно проверить, нельзя ли использовать уже существующий компонент.

## Статус документа

Документ будет постепенно заполняться по мере закрепления стабильных компонентов проекта.
